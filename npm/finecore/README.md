# Repository-only FineCore npm placeholder

This directory is an internal placeholder, not a distribution of the FineCore Rust CLI. It does not reserve the `finecore` name. Its `package.json` sets `private: true` to prevent accidental publication.

The FineCore Rust project is at <https://github.com/oigorbrito/finecore>.
FineCore is based on Orca Harness; see the project repository for upstream attribution and notices. Any functional npm distribution is separate future work; this placeholder must remain private.
